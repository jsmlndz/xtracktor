# Changelog

All notable changes to xtracktor are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

The [verification record](docs/design.md#5-verification-record) lists how each version was tested.

## [1.2.2]

### Fixed

- `tools/baseline.sh` builds the test bank in a new temporary folder for each run and removes only that folder when it exits, including after a failure or Ctrl-C. Before, it deleted `/tmp/fx` (or the folder named by an `FX` environment variable) without checking what was in it. The tool itself and its output are unchanged, and so is the reference fingerprint.

## [1.2.1]

### Fixed

- The legend line of the `zones` report printed `%%midi` / `%%<=frames` instead of `%midi` / `%<=frames`. Nothing reads that line, and the output fingerprint in `tools/baseline.sh` is unchanged.

## [1.2.0]

### Changed

- Renamed the synthetic test bank's bank, preset, file and header names. It still reproduces every quirk of the real banks.
- New reference fingerprint in `tools/baseline.sh`, because the test bank's output changed.
- The engine is unchanged: every module except the test bank is identical to 1.1.0 apart from comments and the version number.

## 1.1.0

### Added

- `tools/baseline.sh` checks the output against a fixed reference fingerprint (the MATCH check).

### Changed

- Test-bank seeds come from CRC-32 instead of Python's `hash()`, so the test bank is byte-identical on every machine, Python version and `PYTHONHASHSEED`.
- The first line of every SFZ now reads `// generated by xtracktor from .mse zone data`.

## 1.0.0

Five single-purpose scripts (`mse_index.py`, `pitch_check.py`, `wav_check.py`, `mse_survey.py`, `make_quirk_fixture.py`) consolidated into one CLI. Output is byte-identical on a clean run.

### Added

- The `audit` summary counts `zone-mismatch`.

### Changed

- `survey` uses mmap + regex instead of a whole-file read and a per-byte loop. On a 384 MB bank, private memory dropped from 401 MB to 26 MB, and it runs 3.5× faster.
- `pitch` reads only its 4,096-frame analysis window instead of the whole file.
- Merged duplicate readers: five RIFF chunk readers became one walker, two string scanners became one, and zone reading is unified.

### Fixed

- Atomic writes: Ctrl-C during `extract` no longer leaves a partial WAV under its real name. Nothing is left behind, and the exit status is 130.
- `verify --max` now works; it was a no-op.
